## About the System

Bespoke web platform engineered for the San Luis Sports Secretariat to manage provincial School Athletics Championships with over 5,000 competing athletes.

### Technical Highlights:
- **Resilient Backend:** Java 17, Spring Boot, Spring Security, and MySQL database.
- **Interactive UI:** Next.js dashboard with live track results, heats, and rankings.
- **Role-based Access Control:** Dedicated portals for track judges, coordinators, and school delegates.
